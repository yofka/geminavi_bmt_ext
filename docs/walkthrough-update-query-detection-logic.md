# Heading Detector 改善 完了報告
2026/02/16 22:52

## 1. ハイライト機能の強化

- **デフォルトでオフ**: ハイライト機能は初期状態でオフ。
- **色カスタマイズ**: ⚙️設定パネルから各レベル（H1-H6, Q, A）ごとのハイライト色を設定可能。
- **リアルタイム反映**: 色変更は即座にページ上のハイライトに反映。

## 2. Gemini クエリ検出の完全修正 ✅

`query-text` クラスを持つ要素が H5 として表示されたり、サイドパネルで消えてしまう問題を解消しました。

### 根本原因
Gemini 専用の検出パス (`detectGeminiChatItems`) がクエリ要素を捕捉できなかった場合、後続の**ネイティブ見出しループ** (`h1-h6, [role="heading"]`) が同じ要素を `aria-level="5"` → `H5` として登録してしまっていた。

### 修正内容
- ネイティブ見出しループに **`query-text` クラスのオーバーライド** を追加
  - `className` に `query-text` を含む要素は H タグのレベルに関係なく **`level: 2, isQuery: true`** に強制
  - `[H1] Gemini との会話` の直下に `[Q]` としてぶら下がる
- "You said" 等の隠しテキストを `cloneNode` + 正規表現で自動除去
- `heading-detector.js`（拡張機能）と `bookmarklet.js` の両方に同一修正を適用

## 3. UI 配置の改善

- コントロール類（自動更新・凡例）を下部から上部に移動し、ホバーオーバーレイ内に配置。
