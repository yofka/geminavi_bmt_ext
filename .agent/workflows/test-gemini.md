# Gemini テストワークフロー

このワークフローは、Gemini で拡張機能とブックマークレットの目次表示機能をテストします。

## 前提条件

- ビルドが完了していること（`/build` を先に実行）
- Chrome に拡張機能がインストール済み
- Gemini (gemini.google.com) にログイン済み

## 拡張機能のテスト

### サイドパネルテスト（最重要）

1. Chrome で `chrome://extensions` を開く
2. 「Heading Detector」の更新ボタンをクリック
3. **新しいタブで** https://gemini.google.com を開く
4. いくつかの会話がある状態にする（既存の会話でもOK）
5. 拡張機能アイコンをクリック → サイドパネルを選択
6. **確認項目:**
   - [ ] サイドパネルに目次が表示されるか
   - [ ] 💬Q（クエリ）と 💭A（応答）のバッジが表示されるか
   - [ ] Hバッジチェックがオフの状態ではH1-H6バッジは非表示か
   - [ ] Hバッジチェックをオンにすると [H2][💬Q] のように両方表示されるか
   - [ ] 見出しをクリックすると該当箇所にスクロールするか

### ポップアップテスト

1. 拡張機能アイコンをクリック → ポップアップを選択
2. **確認項目:**
   - [ ] ポップアップに目次が表示されるか
   - [ ] サイドパネルと同じ内容か

### 自動更新テスト

1. サイドパネルを開いた状態で
2. Gemini に新しい質問を送信
3. **確認項目:**
   - [ ] 新しいQ/Aが自動的に目次に追加されるか
   - [ ] 「更新: HH:MM:SS」と表示されるか

## ブックマークレットのテスト

### セットアップ

1. `dist/bookmarklet/index.html` をブラウザで開く
2. 「Heading Detector」リンクをブックマークバーにドラッグ

### テスト実行

1. https://gemini.google.com を開く（会話がある状態）
2. ブックマークをクリック
3. **確認項目:**
   - [ ] ウィジェットが画面右下に表示されるか
   - [ ] 💬Q（クエリ）と 💭A（応答）が表示されるか
   - [ ] 見出しをクリックすると該当箇所にスクロールするか
   - [ ] Wrap、ドック（⇦/⇨）ボタンが動作するか
   - [ ] 検索機能が動作するか

## 失敗時のチェックポイント

### サイドパネルで目次が表示されない場合

1. コンソール（F12 → Console）でエラー確認
2. 「ページを再読み込みしてください」エラー → ページをリロード
3. それでも失敗 → 新しいタブで開き直す

### ブックマークレットで目次が表示されない場合

1. ビルド時刻が最新か確認（`dist/bookmarklet/index.html`）
2. ブックマークを再登録
3. コンソール（F12 → Console）でエラー確認

### 重複して表示される場合

1. 同じ見出しが Q, Q, H2 のように複数表示 → `heading-detector.js` の重複チェックを確認
2. `DEVELOPMENT.md` の「やってはいけないこと」セクションを確認

## 期待される結果例

```
📌 全体: 15 件  💬 Q: 5  💭 A: 5

▼ 💬Q 最初の質問
  ▼ 💭A はじめに、...
    ▶ H2 セクション1
    ▶ H2 セクション2
▼ 💬Q 2番目の質問
  ▼ 💭A この質問については...
```
