# Heading Detector 🔍

スタイル解析による見出し検出ツール。見出しタグ (`<h1>`〜`<h6>`) がないページでも、CSSスタイル（フォントサイズ、太字、余白など）を解析して見出しらしい要素を特定します。

## 機能

- **スタイル解析**: フォントサイズ、太字、ブロック表示、余白などからスコアを計算
- **レベル推定**: フォントサイズ比率から H1〜H6 相当のレベルを推定
- **ハイライト表示**: 検出した見出しを色分けしてハイライト
- **ネイティブ対応**: 既存の見出しタグも一覧に含めて表示

## インストール

### ブックマークレット版

1. `dist/bookmarklet.txt` の内容をコピー
2. ブラウザで新しいブックマークを作成
3. URL欄にコピーした内容を貼り付け
4. 任意のページでブックマークをクリックして実行

### Chrome拡張機能版

1. Chromeで `chrome://extensions/` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. `extension/` フォルダを選択
5. 任意のページで拡張機能アイコンをクリック

## 使い方

### ブックマークレット

1. 任意のページでブックマークをクリック
2. 検出結果がアラートで表示
3. F12でコンソールを開くと詳細を確認可能
4. ページ上の見出しがハイライト表示される

### Chrome拡張機能

1. 拡張機能アイコンをクリック
2. 「見出しを検出」ボタンをクリック
3. 検出された見出しがリスト表示される
4. リストの項目をクリックすると該当箇所にスクロール
5. 「クリア」ボタンでハイライトを解除

## 検出アルゴリズム

以下の要素を組み合わせてスコアを計算し、40点以上で見出し候補と判定：

| 条件 | スコア |
|------|--------|
| 本文の1.15倍以上のフォントサイズ | +30 |
| 太字 (font-weight: 600以上) | +25 |
| ブロック要素 | +15 |
| 上部マージン/パディング | +10 |
| 下部マージン/パディング | +5 |
| 50文字以下のテキスト | +10 |
| 20文字以下のテキスト | +5 |
| クラス/IDにheading等の文字列 | +15 |

## 制限事項

- CSP（Content Security Policy）が厳しいサイトでは、ブックマークレット版が動作しない場合があります
- Chrome拡張機能版は `scripting` API を使用するため、CSP制限のあるサイトでも動作します
- Shadow DOM内の要素は検出対象外です
