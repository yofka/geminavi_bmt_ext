# Gemini navigation window 🔍

Microsoft WordのナビゲーションウィンドウのようなGemini向けナビゲーションツール。スタイル解析により見出しを検出し、ドキュメント構造をツリービューで表示します。見出しタグ (`<h1>`〜`<h6>`) がないページでも、CSSスタイル（フォントサイズ、太字、余白など）を解析して見出しらしい要素を特定し、クリックで該当箇所にジャンプできます。

## 機能

- **ツリービュー表示**: 見出しを階層構造でナビゲーションパネルに表示
- **スタイル解析**: フォントサイズ、太字、ブロック表示、余白などからスコアを計算
- **レベル推定**: フォントサイズ比率から H1〜H6 相当のレベルを推定
- **ハイライト表示**: 検出した見出しを色分けしてハイライト
- **ネイティブ対応**: 既存の見出しタグも一覧に含めて表示
- **サイドパネル**: ブラウザのサイドバーに常時表示可能
- **検索機能**: 見出しをキーワードで絞り込み

## インストール

### Chrome拡張機能版

1. Chromeで `chrome://extensions/` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. `dist/chrome/` フォルダを選択
5. 任意のページで拡張機能アイコンをクリック

### Firefox拡張機能版

1. Firefoxで `about:debugging#/runtime/this-firefox` を開く
2. 「一時的なアドオンを読み込む」をクリック
3. `dist/firefox/manifest.json` を選択
4. 任意のページで拡張機能アイコンをクリック

### ブックマークレット版

1. `dist/bookmarklet.txt` の内容をコピー
2. ブラウザで新しいブックマークを作成
3. URL欄にコピーした内容を貼り付け
4. 任意のページでブックマークをクリックして実行

## 使い方

### ブラウザ拡張機能（Chrome / Firefox）

1. 拡張機能アイコンをクリックしてポップアップを表示
2. 検出された見出しがツリービューで表示される
3. 項目をクリックすると該当箇所にスクロール
4. 展開レベルボタン（1〜6, A）で表示階層を調整
5. サイドパネルで常時表示も可能

### ブックマークレット

1. 任意のページでブックマークをクリック
2. 検出結果がアラートで表示
3. F12でコンソールを開くと詳細を確認可能
4. ページ上の見出しがハイライト表示される

## 検出アルゴリズム

以下の要素を組み合わせてスコアを計算し、40点以上で見出し候補と判定：

| 条件 | スコア |
|------|--------|
| 本文の1.15倍以上のフォントサイズ | +30 |
| 太字 (font-weight: 600以上) | +25 |
| ブロック要素 | +15 |
| 上部マージン/パディング | +10 |
| 下部マージン/パディング | +5 |
| 50文字以下のテキスト | +10 |
| 20文字以下のテキスト | +5 |
| クラス/IDにheading等の文字列 | +15 |

## ビルド

開発用ソースから配布用ファイルをビルドするには：

```bash
node scripts/build.js
```

これにより `dist/chrome/` と `dist/firefox/` にそれぞれのブラウザ向け拡張機能が生成されます。

## 制限事項

- CSP（Content Security Policy）が厳しいサイトでは、ブックマークレット版が動作しない場合があります
- ブラウザ拡張機能版はCSP制限のあるサイトでも動作します
- Shadow DOM内の要素は検出対象外です
